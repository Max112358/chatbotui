# NanoGPT Chat

A frontend-only ChatGPT-style interface for NanoGPT.

Access at https://max112358.github.io/chatbotui/

## Features

- Stores your NanoGPT API key in browser localStorage
- Conversation history sidebar
- Streaming chat responses
- Text, PDF, and image attachments
- Local-only storage with automatic eviction of oldest conversations
- Vite + React + TypeScript + Tailwind CSS

## Setup

```bash
npm install
npm run dev
```
